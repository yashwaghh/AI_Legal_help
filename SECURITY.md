# Security policy

ClearClause is an early legal-information demo. Do not upload confidential, privileged, or client legal documents. Uploaded text is sent to Vertex AI, and the application does not provide a formal document-retention or deletion workflow.

## Reporting a vulnerability

Please do not publish credentials, personal data, document contents, or a working exploit in a public issue. Use GitHub's private vulnerability reporting for this repository when available. If private reporting is unavailable, contact the repository owner through a private channel and share only the minimum information needed to reproduce the issue.

Do not test against other users' accounts or upload real legal documents while investigating a vulnerability. The public demo uses per-account quotas but does not have Cloud Armor IP filtering.

## Supported code

The `main` branch is the current prototype. There is no production support or service-level agreement. Report the affected commit or revision, impact, and a minimal synthetic reproduction where possible.
